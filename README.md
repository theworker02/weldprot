# weldprot

Weld structured JSON prot payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/weldprot/

## Install / run

```bash
git clone https://github.com/theworker02/weldprot.git
cd weldprot
node src/cli.js
node --test
```
